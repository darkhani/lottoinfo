# 로또 정보 포털 v3.0

현대적인 디자인의 로또 정보 포털 사이트입니다.

## 주요 기능

### 1. 홈 페이지 (번호 뽑기)
- 히어로 섹션 디자인
- 번호 뽑기 애니메이션 효과
- 번호 저장 기능 (로컬스토리지)
- 공유 기능
- 여러 게임 한 번에 뽑기
- 최다 당첨번호 TOP 6 표시

### 2. 당첨번호 조회
- 테이블/카드/그리드 뷰 전환
- 고급 필터링 (년도, 월, 번호, 날짜 범위)
- 실시간 검색
- 번호 클릭 시 하이라이트
- 페이지네이션
- 최다 당첨번호 표시

### 3. 통계/분석
- 번호별 빈도수 차트
- 히트맵 시각화
- 홀짝 비율 분석
- 구간별 분포 분석
- 통계 기반 추천 번호

## 디자인 특징

- **현대적인 UI/UX**: 그라데이션, 글래스모피즘 효과
- **다크 모드 지원**: 라이트/다크 모드 전환
- **반응형 디자인**: 모바일, 태블릿, 데스크톱 최적화
- **애니메이션 효과**: 부드러운 전환 및 인터랙션
- **웹폰트**: Pretendard 폰트 적용

## 설치 방법

1. **파일 업로드**
   - `dev3.0` 폴더 전체를 서버에 업로드
   - cafe24의 경우 `www` 또는 `public_html` 폴더에 업로드

2. **데이터베이스 설정**
   - `includes/functions.php`에서 데이터베이스 연결 정보 확인
   - 기본값: `localhost`, `darkhani`, `a4353488a`, `darkhani`

3. **로고 이미지**
   - `myhitlogo.jpg` 파일이 `dev3.0` 폴더에 있는지 확인
   - 없을 경우 상위 폴더에서 복사

4. **권한 설정**
   - PHP 파일 실행 권한 확인
   - `api` 폴더의 PHP 파일들이 실행 가능한지 확인

## 사용 방법

### 홈 페이지
- `index.php` 접속
- "번호 뽑기" 버튼 클릭
- 생성된 번호를 저장하거나 공유 가능

### 당첨번호 조회
- `lottoInfo.php` 접속
- 필터를 사용하여 원하는 조건으로 검색
- 테이블/카드/그리드 뷰 전환 가능
- 번호 클릭 시 해당 번호가 포함된 회차 하이라이트

### 통계/분석
- `statistics.php` 접속
- 번호 빈도, 패턴 분석, 예측 도구 탭 확인
- 차트와 히트맵으로 시각화된 데이터 확인

## 기술 스택

- **Backend**: Pure PHP
- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **차트**: Chart.js
- **폰트**: Pretendard (Google Fonts)

## 주의사항

1. 데이터베이스 연결 정보는 보안을 위해 환경 변수나 설정 파일로 분리하는 것을 권장합니다.
2. 로컬스토리지에 저장된 번호는 브라우저별로 다릅니다.
